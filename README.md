# E-Commerce Data Cleaning & Exploratory Data Analysis (EDA) Dashboard

## Project Overview
This project focuses on data preparation, cleaning, and exploratory data analysis (EDA) of a raw e-commerce dataset. The dataset tracks products, quantities, order an =d customer ids, coupons, and referrals. 

The final deliverable includes a fully cleaned dataset, an operational insights report, and an Excel Dashboard to track key business performance metrics dynamically.


## Key Features & Deliverables
*   **Data Cleaning Pipeline:** Missing value resolution, duplicate validation, and data type normalization.
*   **Descriptive Statistics:** Central tendency analysis (Mean, Median, Count) across core numerical transactional scales.
*   **Operational Insights & Trend Analysis:** Performance metrics across customer payment preferences and conversion funnels.
*   **Analytics Dashboard:** A consolidated executive visual interface.



*   **Software tool used:** Microsoft Excel
